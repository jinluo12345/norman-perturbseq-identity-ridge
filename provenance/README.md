# Reproducibility bundle (release, 2026-10-06)

This directory records the exact inputs and software state used for the current
Norman--Weissman Perturb-seq analysis. The public release is available at
https://github.com/jinluo12345/norman-perturbseq-identity-ridge/tree/v1.0.0.

The source experiment is retrieved from the public scPerturb/Norman--Weissman
release identified in `../data/processed/input_checksums.json`. The listed raw
files are checked by SHA-256 before preprocessing. `panel_manifest.json` records
the 512 output genes, 256 Reactome pathway names, pathway release and the
processed data dimensions used by the manuscript. `source_manifest.sha256`
records hashes for the analysis source, manuscript source, numerical result
objects and final figure assets. `environment_lock.txt` records package
versions from the workspace `.venv`; it is an observation of the environment,
not an installation command.

The manuscript can be rebuilt from `../paper/main.tex` after the numerical
result files and figure assets have been produced. The analysis scripts are in
`../src/`; the final quantitative figures are generated by
`plot_fig2_repaired_performance.py`, `plot_fig3_repaired.py`,
`plot_fig4_repaired_ablation.py`, `plot_fig5_repaired_upgrade.py` and
`plot_intervention_priority.py`. The conceptual Fig. 1 asset is the native
image2 PNG recorded in `../experiments/image2_fig1_generation_20261006_round4.json`.

The public release contains the selected source, frozen processed arrays,
numerical result objects, final figure assets, native image2 provenance,
manifests, hashes, environment lock and reconstruction recipe. Raw h5ad files
remain available from GSE133344 and are referenced by source checksums.

For local handoff, `source_bundle_round8.tar.gz` is retained as a superseded
internal snapshot. The public release manifest in the GitHub tag is the
canonical file-level integrity record.
